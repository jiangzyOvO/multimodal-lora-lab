# 合成设备铭牌数据集 v1

600 张 672×448 PNG 图片，用于从铭牌中提取型号、电压和功率。图片、字段标签和绘图规格由 [generate_nameplates.py](../../scripts/generate_nameplates.py) 生成，随机种子为 20261009。

|集合|数量|模板|字段完整|每种字段缺失|
|---|---:|---|---:|---:|
|train|400|T01–T08|280|各 40|
|val|100|V01–V02|70|各 10|
|test|100|E01–E02|70|各 10|

型号组、模板 ID 和相同图片文件不跨集合重复。模板之间仍共享字体、布局组件、字段名称和任务语义；这是合成数据上的评估，不是真实照片的跨域测试。

## 文件

- `train.json`、`val.json`、`test.json`：LLaMA-Factory ShareGPT 格式记录。
- `images/`：600 张固定实验图片。
- `metadata.jsonl`：逐图型号组、模板、显示文字、绘图坐标、答案、缺失方式和图片哈希。
- `manifest.json`：生成种子、Pillow 版本、集合统计、字体及数据文件哈希。

样本中的图片路径相对于项目 `data/`，例如 `nameplates_v1/images/99f58bad21059c67.png`。`messages[0]` 是带一个 `<image>` 占位符的输入；`messages[1].content` 是标准 JSON 答案的字符串。

## 标签规则

- 型号按图片原样抄录。
- 电压去除 AC/DC 和空格，保留数字及 V。
- 功率去除空格，保留数字及 W。
- 字段未出现、空白或标为 `--`、`N/A` 时使用 JSON `null`。
- 不根据其他字段推测缺失值。本版本的非空电压和功率均为整数。

## 检查和重新生成

在仓库根目录运行 `.venv/bin/python scripts/verify_repository.py`，检查数据文件及图片哈希、解码、标签结构与集合划分。标签与绘图规格来自同一生成器，两者一致不等于独立人工核验了每一张图片。

本版本使用 macOS 的 PingFang、Hiragino Sans GB、STHeiti Light、Songti 字体。仓库不包含字体文件。精确再生成依赖字体版本、Pillow 版本和绘图逻辑；现有图片可直接用于训练，不需要重新渲染。

本数据中的型号、序列号和参数由程序合成，不对应真实设备技术规格。修改数据或提示后应使用新的版本和输出目录，并重新建立基线。
