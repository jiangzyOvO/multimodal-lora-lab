# v2 合成铭牌与受控数据扩充

生成种子为 20261010，图像为 672×448。标签沿用 v1 的整数 V/W 规范。所有设备型号和参数均为程序合成，不对应真实设备规格。

|集合|图片数|独立父组数|内容|
|---|---:|---:|---|
|train_control_extra|400|100|普通扩充，70% 字段完整、30% 缺失|
|train_hard_extra|400|100|每组包含完整、空白、字段未出现、缺失标记四张图|
|train_control|800|原训练集＋100 个新父组|原 v1 400 张训练图＋普通扩充|
|train_hard|800|原训练集＋100 个新父组|原 v1 400 张训练图＋困难扩充|
|val|200|50|成对样本；新布局；已见/未见字体与数值交叉覆盖|
|test|200|50|另外的父组、布局和未见数值；用于模型固定后的最终测试|

两组新增训练数据共享父组身份、字体和模板。普通组在组内改变字段排列，困难组保持上下文一致，只改变目标字段的缺失状态。两个训练组之间共享部分完整图片是有意设计的；单个训练组内以及不同集合之间不允许相同图片字节。实验比较整套数据配方，无法将结果单独归因于缺失比例或成对构造中的某一个因素。

每组困难样本只针对一个字段，父组之间轮换型号、电压、功率。val/test 各有 50 张完整图和 150 张缺失图，因此整体分布不是业务发生率的估计。统计时同时报告切片分母、整组四张全对数和按父组重采样的配对差异区间。

## 数据版本与检查

`metadata.jsonl` 保存父组、集合、训练组、绘图文本、边界框、字段顺序、缺失方式、字体和图片哈希。`manifest.json` 保存生成器、v1 绘图器、字体与数据文件的指纹。`dataset_info.json` 是本版本独立注册表，不修改 v1 注册表。

```bash
.venv/bin/python scripts/verify_nameplates_v2.py
```

检查包括 1,200 张新图片的解码和哈希、绘图文字与答案匹配、成对样本的非目标字段不变、父组/型号/模板/图片跨集合隔离，以及原 v1 训练记录完整保留。绘图规格检查仍不是对全部图片逐张人工 OCR 校对。

验证集新增字体为 STHeiti Medium；测试集新增字体为 Arial Unicode。约一半父组使用各自未见字体，约一半使用未见数值，二者交叉分配。所有集合仍共享 v1 绘图组件，不能视为真实照片评估。

精确重绘需要 manifest 所列字体及 Pillow 版本。已有图片可直接使用。新实验先固定 `protocol.json`，在验证集选定两组 checkpoint 并保存 `selection.json` 后，才读取最终测试集做推理。
